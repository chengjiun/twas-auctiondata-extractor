本專案使用 **Poetry** 進行虛擬環境隔離與相依套件管理，自動化操作「台灣證券商同業公會」（TWSA）承銷公告系統，同步下載每筆標案的**【開標統計表】**與**【招標說明書】**雙重 PDF，萃取全維度競價拍賣核心數據，並自動計算量化投資與避險關鍵指標，最終匯出為結構化 CSV (`auction_records.csv`)。

## 一、量化投資專家視角：核心指標定義與實務意義

在台股市場（IPO 初次上市櫃、SPO 現金增資、可轉換公司債 CB 競拍）的量化避險與事件型套利（Event-driven Arbitrage）策略中，單看得標價是不夠的。本專案特別擴充雙重 PDF 條款解析，萃取以下全流程供需與風控維度：

1. **【發券日期】（預計撥券入帳日 / 掛牌上市櫃日）**：
   - 來源：招標說明書條款（「*通知集保公司於 XX 年 XX 月 XX 日將有價證券直接劃撥至認購人集保帳戶*」）。
   - **量化意義（交割持有天數 Days to Delivery, D2D）**：$$\text{交割持有天數} = \text{發券日} - \text{開標日}$$
     - 衡量**避險期間長度（Hedge Horizon）**與**資金利息成本（Carry Cost）**。
     - 若開標至掛牌交割相隔 11~17 天，期間承受之系統性風險（Market Beta）與個股波動風險極高，量化交易員需藉由現股借券（SBL）或股票期貨（SSF）進行動態對沖。
2. **【競標張數】vs【合格投標數量】vs【總得標張數】（競拍供需三部曲）**：
   - **競標張數（仟股/張）**：招標說明書規劃提出之競價拍賣數量。
   - **合格投標數量（仟股/張）**：實際送件並審核合格之總投標需求量。
   - **總得標張數（仟股/張）**：開標後最終確定配售之得標張數。
   - **量化意義（投標倍數 / 超額認購倍數 Bid-to-Cover Ratio）**：
     $$\text{投標倍數} = \frac{\text{合格投標數量}}{\text{總得標張數}}$$
     - 衡量機構法人與大戶對該標案的狂熱度，倍數高於 4~5 倍通常意味著掛牌初期籌碼極度惜售。
3. **【公開申購張數】（散戶抽籤配售張數）**：
   - 來源：招標說明書條款（「*其中 XX 仟股以公開申購配售辦理*」）。
   - **量化意義（散戶籌碼分佈與首日賣壓）**：$$\text{公開申購佔比} = \frac{\text{公開申購張數}}{\text{承銷總張數}} \times 100\%$$
     - 股票案件：區分機構法人大戶競拍籌碼 vs 散戶抽籤籌碼的供需失衡度。抽籤價差若高，掛牌當日的散戶拋壓（Retail Selling Pressure）越大。
4. **【員工內部申購張數】（員工認購張數）**：
   - 來源：招標說明書依《公司法》第 267 條規定保留條款（「*依規定保留 XX 仟股供公司員工認購*」）。
   - **量化意義（內部人持股與股權激勵）**：$$\text{員工認購佔比} = \frac{\text{員工認購張數}}{\text{承銷總張數}} \times 100\%$$
     - 反映企業員工持股意願、內部籌碼安定度，以及對外公開釋股比例的真實稀釋程度。
5. **【券商保留自行認購張數】**：
   - 來源：招標說明書承銷商包銷保留條款（「*證券承銷商先行保留自行認購數量: XX 張*」）。
6. **【競拍加權溢價率 (%)】**：
   $$\text{溢價率} = \frac{\text{得標加權平均價} - \text{最低承銷底價}}{\text{最低承銷底價}} \times 100\%$$
   - 衡量市場對該標案的競價狂熱度與潛在折溢價套利空間。

## 三、一鍵執行：全維度量化數據抓取

執行以下指令，腳本將自動查詢指定年份公告，由最新標案開始向前掃描，**自動略過尚未開標之標案，精準下載並萃取「開標統計表 + 招標說明書」雙重 PDF**：

```bash
# 1. 一鍵全量批次產製：取得 2009 年至今 (民國 98~115 年) 所有歷年資料，每年獨立匯出一個 CSV 檔案
poetry run python run_pipeline.py --all-years

# 2. 依自訂年份範圍批次產製：
poetry run python run_pipeline.py --start-year 2016 --end-year 2026 --yearly

# 3. 抓取單一年份 (例如 2025 年最近 60 筆)：
poetry run python run_pipeline.py --year 2025 --limit 60 --output-csv output/auction_records.csv

# 4. 抓取最新年度標案：
poetry run python run_pipeline.py --year 2026 --limit 50 --output-csv output/auction_records_2026.csv
```

### 匯出檔案清單 (`output/` 目錄)
執行 `--all-years` 後，將在 [`output/`](file:///Volumes/XPG1TP-MAC/homeX/chengjiun/workspace/aiworks/twsa-data-download/output/) 自動生成各年份獨立 CSV 以及歷史合併總表：
- `output/auction_records_2009.csv` 至 `output/auction_records_2026.csv`（每年各一個獨立 CSV，即使該年無紀錄亦具備完整 33 欄位標準標頭）
- `output/auction_records_2009_2026_all.csv`（歷年全量合併總表）
- `output/auction_records.csv`（最新全量總表）
